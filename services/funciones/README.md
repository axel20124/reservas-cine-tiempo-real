# Servicio de Funciones

Catálogo de funciones (película, sala, horario). Contrato en `docs/openapi-cine.yaml`.

1. Copiá `.env.example` a `.env` y completá `DB_PASSWORD` y `JWT_SECRET` (el mismo que usa Asientos).
2. `npm install`
3. `npm run db:init`
4. `npm start` (puerto 3002 por defecto) / `npm test`
